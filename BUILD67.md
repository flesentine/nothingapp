# Build 67

Recovery itself became a security. Build 66 gave a title insurer a subrogation claim against the first lender after the insurer paid cash for a Build 65 ownership loss. That recovery arrived slowly because Build 66 deliberately swept only excess clearing-house liquidity. Build 67 adds the Interreality Subrogation Recovery Market and asks the next consequence: if an insurer expects money later, why should it wait before using that expectation as capital today?

An insurer with an active Build 66 subrogation claim can now sell part of that future recovery to a Build 63 investment fund. The instrument is a subrogation-backed recovery note. The fund pays discounted cash up front; the insurer receives immediate capital; and the note receives an assignment over part of the future subrogation stream. The underlying Build 65 title dispute does not change. No sovereign debt disappears. No clearing-house obligation is forgiven. A future insurance recovery is simply spent before it has actually been collected.

Build 67 deliberately reconnects this instrument to Build 52 rather than creating a parallel capital universe. Every recovery note also exists as a real Build 52 insurer obligation with `kind: subrogation-backed surplus note`, a BBB covenant, and principal included in the insurer's existing `debt52` leverage. The note is zero-coupon inside Build 52 because the investor's return is the discount between purchase price and assigned recovery rather than periodic coupon cash. Its Build 52 service clock is parked far in the future so the older autonomous coupon loop does not invent payments to an external holder that is now an actual Build 63 fund.

The old Build 52 rating agencies now also appear on Build 67 recovery-note surveillance records. Recovery-note grades run from AAA through D and are driven mainly by the first lender's liquidity above its operating floor, discounted default-fund and capital resources, the remaining assigned note balance, insurer status, and whether the underlying Build 65 title dispute is still open. A strong clearing house can therefore support a high-grade security even while the underlying ownership dispute remains unresolved.

Build 66 recoveries pass through automatically. When a subrogation claim reports additional recovered cash, that amount has already entered the insurer's capital through Build 66. Build 67 immediately sweeps the assigned portion from insurer capital to the Build 63 note investor, reduces the recovery note, reduces the parallel Build 52 bond outstanding, and reduces the insurer's `debt52`. A normal full recovery therefore recapitalizes the insurer early while allowing the investor to earn the difference between the discounted issue price and the eventual recovery stream.

This creates a new rating spiral when the first lender weakens before the assigned recovery finishes. If a recovery note falls below BBB, Build 67 creates a real Build 52-shaped collateral call against the insurer and the note's Build 52 bond. Posting collateral traps insurer capital behind the note. Failing the call defaults the note and its Build 52 obligation. Posted collateral goes to the investor, but the investor also keeps the assigned subrogation stream, so future Build 66 recoveries can continue paying after default. A later full recovery is recorded as `recovered-after-default` rather than rewriting the default out of history.

The integration also works in the other direction. If the older Build 52 layer independently creates a collateral call against the same insurer bond because the insurer itself was downgraded, Build 67 can resolve and fund that call even though the call contains no Build 67-specific identifier. Likewise, if Build 52 defaults the bond first, Build 67 detects that existing default without incrementing the Build 52 default counter a second time. The two layers therefore share one obligation rather than pretending they issued two different notes.

If a failed recovery-note collateral call consumes the insurer's remaining capital, Build 67 can make the Build 51 insurer insolvent and orphan both unrelated Build 51 software-risk policies and remaining Build 66 title policies. This creates a longer causal chain than the note itself: a sovereign title dispute creates an insurance payout; the payout creates subrogation; subrogation is securitized; clearing-house weakness downgrades the securitization; the downgrade demands insurer cash; and the resulting insurer failure can remove coverage from software contracts that never owned the sovereign paper.

The deterministic harness uses the Build 66 main-path numbers. A subrogation claim with 2.763848 still outstanding and a first clearing house at 11.45 liquidity supported a 2.2110784 recovery note. The existing A Archive Ratings Bureau graded the note AA, and Clearing Yield Cooperative bought it for 2.012081. When 2.2110784 of later Build 66 recoveries arrived, the note passed the full amount through, retired the associated Build 52 debt to zero, closed as `repaid`, and gave the investor a 0.1989974 gain over issue price.

The stress harness started another note from the same healthy conditions and then reduced the first lender to 6.2 liquidity, 0.1 default fund, and 0.1 capital. The recovery grade fell from AA to BB and generated a 0.509 Build 52 collateral call. With the insurer deliberately left with only 0.3 capital, the call failed after posting that 0.3, the note became `defaulted-assignment`, the insurer became `insolvent`, and unrelated Build 51 and Build 66 policies were both orphaned. A separate compatibility harness created an ordinary Build 52 call with no Build 67 note ID; Build 67 resolved it through the shared bond reference and successfully posted the full 0.4 collateral.

Build 67 persists through `nothing-state-v67`, wraps the existing save/render chain, loads after `title_insurance.js`, and extends the forget action through version 67. It reads and selectively updates Build 51 insurer capital/status and policies, Build 52 rating agencies/bonds/collateral calls/insurer debt, Build 54 clearing-house condition, Build 63 investment-fund cash, Build 65 title disputes, and Build 66 subrogation recoveries. Historical title claims, subrogation payments, rehypothecation chains, and capital defaults remain intact.

New places include `future recovery sold before the clearing house paid it`, `a claim against a lender became debt issued by an insurer`, `insurer recapitalized by selling tomorrow's recovery`, `clearing-house repayment already spent before collection`, and `a recovery-note financing orphaned unrelated insurance`. `recovery_notes.js` passes Node syntax validation, and the instrumented deterministic harness covers discounted issuance, full pass-through repayment, Build 52 debt retirement, recovery-grade downgrade, Build 52 collateral calls, partial collateral default, insurer/policy contagion, legacy Build 52 call compatibility, and double-default prevention.
